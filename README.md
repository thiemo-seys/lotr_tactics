# Model previews

Pictures for the pull requests that add the unit models (one per unit, starting at #57): each model from eight sides in both team colours, rendered with `packages/client/art/preview.py`. The top row is the three-quarter view in blue and red, then the game's camera from behind and from the front; the bottom row is the front, left, back and right.

This branch only hosts the pictures for those pull requests and isn't meant to be merged.
